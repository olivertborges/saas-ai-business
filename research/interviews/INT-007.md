# INT-007 — Inmobiliaria

**Fecha:** 2026-10-01  
**Perfil:** Inmobiliaria / negocio inmobiliario  
**Tipo de entrevista:** Entrevista exploratoria real  
**Estado:** Analizada parcialmente

---

## 1. Hechos registrados

La inmobiliaria indicó que necesita:

- Automatizar el proceso con los clientes.
- Contar con algo que permita comunicarse y gestionar el negocio sin tanta intervención humana.
- Recibir sugerencias para mejorar.
- Obtener ayuda para tomar mejores decisiones estratégicas y saber qué puede funcionar realmente.
- Crear contenido para redes sociales.

---

## 2. Problemas potenciales observados

A partir de las respuestas aparecen varias áreas de necesidad:

### Automatización de clientes
Existe interés en reducir la intervención manual en la comunicación y gestión de clientes.

### Gestión del negocio
La necesidad no se limita a generar contenido. También aparece la gestión general del proceso comercial.

### Recomendaciones estratégicas
La persona busca algo que no solamente ejecute instrucciones, sino que pueda sugerir mejoras y ayudar a decidir qué acciones podrían funcionar.

### Contenido
La creación de contenido para redes sociales continúa apareciendo como una necesidad.

---

## 3. Interpretación / hipótesis

Esta entrevista aporta evidencia exploratoria de que algunos negocios pueden buscar una solución más amplia que la generación de contenido.

Aparecen conjuntamente:

**Clientes → comunicación → gestión → estrategia → contenido → automatización**

Esto podría apuntar hacia una plataforma capaz de coordinar diferentes procesos del negocio.

Sin embargo, esta entrevista por sí sola no permite determinar si existe una demanda suficiente para una plataforma de este alcance.

---

## 4. Lo que todavía NO sabemos

No se validó:

- Cuánto tiempo dedica actualmente a estas tareas.
- Cuánto dinero gasta actualmente.
- Si paga empleados, agencias o software.
- Qué herramientas utiliza.
- Qué parte del proceso consume más tiempo.
- Qué tareas estaría dispuesto a automatizar.
- Qué tareas no confiaría a una IA.
- Cuánto le cuesta actualmente el problema.
- Si pagaría por una solución.
- Cuánto estaría dispuesto a pagar.
- Qué problema considera más urgente.
- Qué resultado concreto considera éxito.

---

## 5. Importancia para la investigación

Esta entrevista refuerza una hipótesis que está apareciendo en otras entrevistas:

> Algunos negocios no buscan únicamente generar contenido, sino reducir el trabajo necesario para mantener y hacer crecer el negocio.

Pero todavía debemos investigar si estas necesidades forman parte de un problema común entre distintos tipos de negocios o si corresponden a necesidades específicas de cada sector.

---

## 6. Estado

🟡 **Evidencia exploratoria**

Esta entrevista aporta señales útiles para la investigación, pero no constituye validación de mercado ni una decisión de producto.
