# Investigación de usuarios

Proyecto: SaaS AI Business
Versión: 0.1
Estado: 🟡 Investigación
Fecha: 2026-10-01

---

## 1. Objetivo

Investigar qué tipos de usuarios podrían experimentar problemas relacionados con la creación, gestión y mantenimiento de su presencia digital.

Este documento no define todavía el mercado objetivo.

Su objetivo es establecer perfiles de investigación que posteriormente puedan compararse mediante evidencia.

---

# 2. Principio

No debemos elegir un segmento únicamente porque:

- parezca grande;
- nos resulte familiar;
- sea fácil de programar para él;
- utilice redes sociales;
- pueda beneficiarse de IA;
- o parezca dispuesto a pagar.

Debemos investigar:

- intensidad del problema;
- frecuencia;
- comportamiento actual;
- soluciones utilizadas;
- gasto;
- disposición a pagar;
- urgencia;
- facilidad de adquisición;
- capacidad de la solución para generar valor.

---

# 3. Perfiles iniciales

## Perfil A — Pequeños negocios

Ejemplos:

- tiendas;
- salones;
- restaurantes;
- cafeterías;
- gimnasios;
- comercios;
- negocios de servicios.

### Problemas hipotéticos

- Poco tiempo para marketing.
- Falta de conocimientos.
- Necesidad de generar contenido constantemente.
- Presupuesto limitado.
- Necesidad de atraer clientes locales.
- Necesidad de mantener redes activas.

### Hipótesis

Podrían valorar una solución sencilla que reduzca el trabajo necesario para mantener su presencia digital.

---

# 4. Perfil B — Profesionales independientes

Ejemplos:

- abogados;
- contadores;
- arquitectos;
- diseñadores;
- fotógrafos;
- consultores;
- coaches;
- profesionales de servicios.

### Problemas hipotéticos

- Poco tiempo.
- Necesidad de construir reputación.
- Necesidad de generar contenido educativo.
- Necesidad de captar clientes.
- Necesidad de mantener una imagen profesional.

### Hipótesis

Podrían valorar especialmente la generación de contenido educativo y la construcción de autoridad.

---

# 5. Perfil C — Emprendedores

Incluye personas que están construyendo:

- nuevos negocios;
- productos;
- servicios;
- marcas;
- proyectos digitales.

### Problemas hipotéticos

- Necesidad de validar ideas.
- Necesidad de conseguir clientes.
- Poco presupuesto.
- Muchas tareas simultáneas.
- Necesidad de crear presencia digital rápidamente.

### Hipótesis

Podrían valorar velocidad y automatización.

---

# 6. Perfil D — Creadores de contenido

Incluye:

- influencers;
- YouTubers;
- streamers;
- creadores independientes;
- personalidades digitales.

### Problemas hipotéticos

- Producción constante.
- Adaptación entre plataformas.
- Calendarios.
- Reutilización de contenido.
- Generación de ideas.
- Analítica.

### Hipótesis

Podrían valorar especialmente la reutilización y adaptación automática.

Sin embargo, algunos creadores ya poseen conocimientos avanzados y herramientas especializadas.

---

# 7. Perfil E — Marcas personales

Incluye personas que utilizan su nombre o identidad como marca profesional.

Ejemplos:

- especialistas;
- consultores;
- educadores;
- profesionales;
- emprendedores.

### Problemas hipotéticos

- Mantener una voz consistente.
- Crear contenido regularmente.
- Construir autoridad.
- Coordinar diferentes plataformas.
- Convertir conocimiento en contenido.

### Hipótesis

Podrían valorar un sistema que conozca profundamente su identidad y conocimiento.

---

# 8. Perfil F — Agencias y profesionales de marketing

Incluye:

- agencias;
- freelancers;
- community managers;
- social media managers;
- consultores de marketing.

### Problemas hipotéticos

- Gestionar múltiples clientes.
- Crear contenido repetidamente.
- Mantener diferentes identidades.
- Preparar calendarios.
- Obtener aprobaciones.
- Reportar resultados.

### Hipótesis

Podrían valorar mucho la automatización y gestión multi-cliente.

Sin embargo, este segmento también tiene necesidades más complejas y podría requerir funcionalidades avanzadas desde el principio.

---

# 9. Perfil G — Empresas pequeñas y medianas

Empresas con equipos internos o externos de marketing.

### Problemas hipotéticos

- Coordinación.
- Escalabilidad.
- Producción de contenido.
- Consistencia de marca.
- Aprobaciones.
- Analítica.

### Hipótesis

Podrían tener mayor presupuesto, pero también expectativas y requisitos mayores.

# 11. Variables que debemos investigar

Para comparar los perfiles necesitamos investigar:

## Dolor

¿Qué tan problemático es mantener la presencia digital?

## Frecuencia

¿Con qué frecuencia aparece el problema?

## Tiempo

¿Cuántas horas requiere actualmente?

## Dinero

¿Cuánto gastan actualmente?

## Herramientas

¿Qué utilizan?

## Sustitutos

¿Utilizan ChatGPT, Canva, freelancers, agencias u otras herramientas?

## Urgencia

¿Necesitan resolver el problema ahora o simplemente sería conveniente?

## Disposición a pagar

¿Pagarían por resolverlo?

## Confianza

¿Permitirían que una IA genere contenido para su negocio?

## Automatización

¿Permitirían que una IA publique contenido directamente?

## Control

¿Qué necesitan revisar antes de publicar?

# 12. Preguntas para entrevistas

Cuando comencemos entrevistas reales, debemos evitar preguntar solamente:

"¿Te gustaría una herramienta que haga X?"

Ese tipo de pregunta puede producir respuestas poco fiables.

Debemos investigar comportamientos reales.

Preguntas iniciales:

1. ¿Cómo gestionas actualmente las redes de tu negocio?
2. ¿Quién crea el contenido?
3. ¿Cuánto tiempo dedicas aproximadamente?
4. ¿Qué herramientas utilizas?
5. ¿Cuánto pagas por ellas?
6. ¿Contratas a alguien?
7. ¿Qué parte del proceso te resulta más difícil?
8. ¿Qué parte repites constantemente?
9. ¿Qué haces cuando no sabes qué publicar?
10. ¿Cómo decides qué publicar?
11. ¿Cómo sabes si algo funcionó?
12. ¿Has utilizado IA para esto?
13. ¿Qué utilizaste?
14. ¿Qué funcionó bien?
15. ¿Qué no funcionó?
16. ¿Qué sigues haciendo manualmente?
17. ¿Qué nunca dejarías completamente en manos de una IA?
18. ¿Qué te gustaría automatizar?
19. ¿Cuánto gastas actualmente en resolver este problema?
20. ¿Qué solución has intentado anteriormente?

# 13. Señales de un problema fuerte

Durante la investigación debemos buscar señales como:

- El usuario ya está pagando por resolverlo.
- El usuario utiliza varias herramientas.
- El usuario dedica muchas horas.
- El usuario repite tareas frecuentemente.
- El usuario contrata profesionales.
- El usuario ha probado diferentes soluciones.
- El usuario se queja de una parte concreta del proceso.
- El usuario considera el problema importante para su negocio.
- El usuario busca activamente una solución.

Estas señales son más útiles que simplemente escuchar:

"Sí, me gustaría tener eso."

---

# 14. Señales de un problema débil

Debemos tener cuidado si encontramos:

- Poco interés.
- Uso ocasional.
- Poca frecuencia.
- Soluciones gratuitas suficientes.
- Falta de disposición a pagar.
- El usuario considera el problema trivial.
- El usuario no utiliza actualmente ninguna solución.
- El usuario no estaría dispuesto a cambiar su comportamiento.
