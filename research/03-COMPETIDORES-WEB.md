# Competidores — Generación de sitios web con IA

Proyecto: SaaS AI Business
Versión: 0.1
Estado: 🟡 Investigación
Fecha: 2026-10-01

---

## 1. Objetivo

Analizar plataformas que utilizan inteligencia artificial para crear sitios web, landing pages o estructuras digitales para negocios.

La investigación busca determinar:

- Qué tan automatizada está la creación web.
- Qué información necesita proporcionar el usuario.
- Qué elementos genera la IA.
- Cuánto trabajo manual queda después.
- Cómo gestionan contenido y marca.
- Qué capacidades de publicación ofrecen.
- Cómo cobran.
- Qué espacio podría existir para una solución integrada con contenido y marketing.

# 2. Wix

Sitio oficial:

https://www.wix.com/

## Producto relevante

Wix utiliza IA para ayudar a crear sitios web a partir de una conversación o descripción de las necesidades del negocio.

## Capacidades observadas

La plataforma puede ayudar a generar:

- Estructura del sitio.
- Diseño.
- Contenido.
- Secciones.
- Imágenes.
- Elementos visuales.
- Funcionalidades específicas del negocio.

El usuario puede posteriormente editar el resultado.

## Modelo conceptual

Usuario describe negocio
↓
IA genera propuesta
↓
Sitio web
↓
Edición
↓
Publicación

## Relevancia

Wix demuestra que la generación de un sitio web completo mediante IA ya es una categoría comercial existente.

Por lo tanto:

"Generar una página web con IA"

no constituye por sí solo una diferenciación suficiente.

# 8. Hallazgos iniciales

## Hallazgo 1 — Crear una web con IA ya es una categoría madura

Existen múltiples plataformas capaces de generar sitios web a partir de información relativamente simple.

Por lo tanto:

"Nuestro producto crea webs con IA"

no sería una diferenciación suficiente.

---

## Hallazgo 2 — La edición posterior es fundamental

Los constructores no terminan en la generación inicial.

El usuario normalmente necesita:

- editar;
- cambiar textos;
- modificar imágenes;
- cambiar estructura;
- ajustar diseño;
- publicar;
- actualizar.

Por lo tanto, debemos estudiar el proceso completo.

---

## Hallazgo 3 — Algunas plataformas combinan web y herramientas de negocio

Especialmente relevantes son las plataformas que combinan:

- sitio web;
- hosting;
- marketing;
- contenido;
- SEO;
- herramientas empresariales.

Esto demuestra que la frontera entre "constructor web" y "plataforma para negocios" está desapareciendo.

---

## Hallazgo 4 — El contexto del negocio vuelve a ser importante

Para generar una web útil, la IA necesita conocer información como:

- qué hace el negocio;
- qué vende;
- para quién;
- ubicación;
- servicios;
- propuesta de valor;
- información de contacto;
- tono;
- identidad visual.

Esto vuelve a conectar directamente con nuestra hipótesis de Business Brain.

Debemos investigar:

4. ¿Qué partes siguen siendo manuales?
5. ¿Cómo se actualiza el sitio?

7. ¿Puede reutilizar contenido generado en otras partes?
8. ¿Puede una campaña generar también una landing page?
9. ¿Puede una modificación del negocio actualizar automáticamente diferentes activos?
10. ¿Qué costes tienen hosting, dominios y generación?
11. ¿Qué tan difícil es migrar o exportar el sitio?

# 10. Hipótesis para nuestro producto

Estas hipótesis todavía no están validadas.

### H1

El Business Brain podría utilizarse para generar un sitio web sin pedir al usuario que vuelva a introducir la información del negocio.

### H2

Una misma fuente de información podría alimentar:

- sitio web;
- publicaciones;
- campañas;
- anuncios;
- emails;
- mensajes;
- perfiles empresariales.

### H3

Una campaña podría generar automáticamente diferentes activos digitales relacionados.

Ejemplo:

Objetivo:
"Promocionar servicio X"

Posibles activos:

- Landing page.
- Instagram post.
- Instagram stories.
- Reel.
- Facebook post.
- TikTok script.
- Email.
- WhatsApp.
- Google Business post.

Esta hipótesis deberá validarse frente a las herramientas existentes.

### H4

El valor podría estar menos en generar cada activo individualmente y más en mantener coherencia entre todos ellos.

---

# 11. Riesgo identificado

Los constructores web con IA están avanzando rápidamente.

Por lo tanto, construir solamente un "AI website builder" podría generar una competencia directa con productos maduros.

La investigación deberá determinar si la web debe ser:

- el producto principal;
- un módulo;
- una consecuencia de tener un Business Brain;
- o una capacidad posterior.

---

# 12. Conclusión provisional

El mercado demuestra que la creación de sitios web mediante IA ya está ampliamente disponible.

Las principales plataformas combinan diferentes grados de:

- generación;
- edición;
- hosting;
- contenido;
- marketing;
- SEO;
- herramientas empresariales.

Por lo tanto, nuestra posible diferenciación deberá estudiarse alrededor del flujo completo del negocio y no únicamente alrededor de la generación automática de sitios.

Hipótesis actual:

Business Brain
→ objetivo
→ estrategia
→ activos digitales
→ web
→ distribución
→ resultados

continúa siendo una hipótesis de investigación y no una decisión definitiva.
